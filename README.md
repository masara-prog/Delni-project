# Delni — دلّني

| المجلد | المحتوى |
|---|---|
| `Delni Platform/` | المنصة: الموقع (React / Vite في `src/`) والخادم (Laravel في `delni-backend/`) — قاعدة البيانات SQL Server ‏DelniDB |
| `App Delni/` | تطبيق الهاتف (Flutter) للسائح والمرشد والسائق، يعمل على نفس خادم Laravel |

## التشغيل
- **المنصة:** من داخل `Delni Platform/` شغّل `تشغيل_منصة_دلني.bat` (خادم Laravel على 8000 والموقع على 8080).
- **التطبيق على الهاتف:** من داخل `App Delni/` شغّل `run_delni.bat` (يشغّل الخوادم إن لزم، يبني التطبيق، يثبته، ويربط المنفذين 8000 و8080 بالهاتف).
  أول مرة: `flutter pub get` داخل `App Delni/`.

> ملف `delni-backend/.env` (بيانات الاتصال بقاعدة البيانات) غير مرفوع؛ لكل جهاز نسخته الخاصة.
