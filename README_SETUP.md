# 🌟 دليل تشغيل منصة دَلِّــنِي للسياحة والسفر في ليبيا (Delni Platform Guide)

مرحباً بك! هذا الدليل يوضح لكِ كيفية تشغيل المنصة بالكامل (الواجهة الأمامية، الخادم الخلفي، قاعدة البيانات، والذكاء الاصطناعي) خطوة بخطوة بكل سهولة ووضوح.

---

## 🏛️ هيكلية المشروع (Project Architecture)

المشروع مبني كـ Full-Stack Monorepo يضم:
- **`src/`**: الواجهة الأمامية الحديثة (React 19 + TanStack Start + Vite + TailwindCSS).
- **`delni-backend/`**: الخادم الخلفي المتكامل (PHP Laravel 12) مع كافة النماذج الـ 28 والمتحكمات.
- **`delniDatabase/delni_database.sql`**: سكربت قاعدة البيانات الكامل لمنصة دلني (Microsoft SQL Server).
- **`delni-ai-service/`**: محرك الذكاء الاصطناعي السياحي وخبير المعالم والرحلات في ليبيا.

---

## 🚀 1. التشغيل السريع للواجهة الأمامية (Frontend)

الواجهة مزودة بنظام **(Safe Fallback)** ذكي للغاية، مما يعني أنها ستعمل عندكِ **فوراً 100% بكامل تصاميمها وشاشاتها** حتى قبل تشغيل قاعدة البيانات أو الباك إند:

1. افتحي موجه الأوامر (Terminal) في مجلد المشروع الرئيسي:
```bash
npm install
npm run dev
```

2. افتحي المتصفح على الرابط:
👉 **`http://localhost:8080`**

وستفتح المنصة مباشرة بكامل المعالم، والرحلات، والتصفح، ونافذة الذكاء الاصطناعي العائمة!

---

## 🗄️ 2. تشغيل قاعدة البيانات (Microsoft SQL Server)

لإنشاء قاعدة بيانات المنصة الـ 27 جدولاً على جهازك:

1. افتحي برنامج **SQL Server Management Studio (SSMS)** أو **Azure Data Studio**.
2. اتصلي بالسيرفر المحلي الخاص بكِ (Local Server).
3. افتحي ملف السكربت الموجود داخل المشروع:
   📁 `delniDatabase/delni_database.sql`
4. اضغطي على زر **Execute** (أو F5).
5. سيتم إنشاء قاعدة بيانات باسم **`DelniDB`** تحتوي على كافة الجداول والعلاقات والقيود تلقائياً.

---

## ⚙️ 3. تشغيل الخادم الخلفي (Laravel Backend)

لتشغيل الـ API وربطه مع قاعدة البيانات `DelniDB`:

1. انتقلي إلى مجلد الخادم الخلفي:
```bash
cd delni-backend
```

2. تثبيت حزم لارفيل:
```bash
composer install
```

3. تجهيز ملف الإعدادات البيئية:
```bash
copy .env.example .env
php artisan key:generate
```

4. تأكدي من تفعيل تعريفات `sqlsrv` و `pdo_sqlsrv` في ملف `php.ini` الخاص بـ PHP على جهازك.

5. تشغيل خادم لارفيل:
```bash
php artisan serve --port=8000
```

6. يمكنكِ التأكد من عمل الخادم واختبار الاتصال بالداتا بيز بفتح:
👉 `http://127.0.0.1:8000/api/health`
وسيعطيكِ استجابة سريعة:
```json
{"status":"online","service":"Delni Laravel API","database":"sqlsrv"}
```

## 🤖 4. تشغيل خدمة الذكاء الاصطناعي (Python AI Service) — (اختياري)

المنصة تحتوي على بديل ذاتي ذكي مدمج في الواجهة وخادم لارفيل لا يتوقف أبداً، ولكن لتشغيل الخادم الأصلي المستقل:

1. انتقلي إلى مجلد خدمة الذكاء الاصطناعي:
```bash
cd delni-ai-service
```

2. تثبيت الحزم المطلوبة:
```bash
pip install -r requirements.txt
```

3. تشغيل خادم FastAPI:
```bash
uvicorn main:app --reload --port 8001
```
