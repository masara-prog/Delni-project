# تطبيق دلني للسياحة في ليبيا (Flutter App) 🇱🇾

تطبيق موبايل هجين مطور باستخدام **Flutter & Dart** مع دعم كامل للغتين العربية والإنجليزية واتجاه RTL.

## 📁 هيكلية المشروع
```
delni_flutter/lib/
├── main.dart            # تشغيل التطبيق، اللغة، والتوجيه حسب الدور
├── api_service.dart     # الربط مع Laravel API (إعدادات الخادم كما هي)
├── models.dart          # نماذج البيانات المقروءة من الخادم
├── core/                # الألوان والخطوط (theme)، اللغة AR/EN، التنسيق، حالة التطبيق
├── widgets/             # مكونات التصميم الموحدة (أزرار، حقول، بطاقات، حالات التحميل والفراغ والخطأ)
└── screens/
    ├── auth/            # اختيار الدور، الدخول، إنشاء الحساب، طلب المرشد، استعادة كلمة المرور
    ├── tourist/         # الرئيسية، استكشف، تفاصيل الرحلة والحجز، حجوزاتي، الرحلة الخاصة، حسابي
    ├── guide/           # لوحة المرشد ورحلاته وقائمة المسافرين
    ├── driver/          # لوحة السائق والمركبة ومرحلة الرحلة
    └── shared/          # الإشعارات، الدعم، الرسائل
```
الخطوط (Cairo و Tajawal) مضمّنة في `assets/fonts`.

## 👥 ممثلو النظام (Actors)
1. **السائح (Tourist)**:
   - تصفح الرحلات اليومية والأسبوعية مع تفاصيل المسار والأسعار بالدينار الليبي.
   - حجز فوري للمقاعد.
   - استعراض المرشدين المعتمدين من وزارة السياحة والآثار مع الاتصال المباشر.
   - بطاقات صعود وتذاكر رقمية مزودة بـ **QR Code**.

2. **المرشد السياحي (Tour Guide)**:
   - قائمة المسافرين وجولة اليوم الميدانية (**المانيفست**).
   - زر التحضير السريع (Check-in) للركاب عند صعود الحافلة.
   - تبديل حالة الجاهزية لاستقبال الرحلات (متاح / مشغول).
   - بطاقة الاعتماد والترخيص الحكومي الرسمي وإحصائيات الرحلات.

## 🚀 تشغيل التطبيق
للتشغيل على نظام التشغيل Windows:
```bash
cd "تطبيق دلني\delni_flutter"
flutter run -d windows
```

أو للتجربة على المتصفح (Web / Edge):
```bash
flutter run -d edge
```

أو للتجميع لنظام Android (APK):
```bash
flutter build apk --release
```
